UPI ID and UPI Number Guide

What Is a UPI ID?

A UPI ID, also known as a Virtual Payment Address (VPA), is a unique payment identifier that allows a person or business to send and receive money through the Unified Payments Interface (UPI) without sharing bank account details with every payer.

A UPI ID is created or assigned through a supported UPI application and is linked to an eligible bank account or another supported payment instrument. It acts as an address that helps direct a payment to the intended recipient.

How a UPI ID works

  1. Creation: The user registers with a supported UPI application and completes the required verification.
  2. Account linking: The user links an eligible bank account or supported payment instrument, where permitted.
  3. UPI ID assignment: The application provides an available UPI ID or allows the user to select one from the options offered.
  4. Payment initiation: A payer enters the recipient's UPI ID or selects it through a supported contact or payment interface.
  5. Recipient verification: The payer checks the recipient's displayed name before proceeding.
  6. Authentication: For a payment that requires a UPI PIN, the payer enters their PIN to authorise the debit.
  7. Transaction completion: The UPI system processes the transaction and provides a status, such as successful, pending, or failed.

Example of a UPI ID

rahul123@bankname

This is an illustrative example. The part before the @ symbol identifies the user-selected or assigned address, while the suffix identifies the payment provider or addressing system. The exact format depends on the issuing provider.

Important points

  • A UPI ID is not the same as a bank account number.
  • It can be used to send or receive payments through compatible UPI services.
  • A user may have more than one UPI ID, depending on the application and account configuration.
  • A UPI ID should not be assumed to reveal the recipient's complete bank account details.
  • A UPI ID is not a password or a substitute for payment authentication.

Practical example: A shopkeeper can display a business UPI ID at a payment counter. Customers can enter the ID in their UPI application, verify the displayed business name, and pay without manually entering the shopkeeper's bank account number.

What Is a UPI Number?

A UPI Number is a numeric identifier that can be used to identify a UPI user for payments through services that support this feature. Depending on the provider's implementation, it may be a mobile number or another supported numeric identifier registered for UPI payments.

In India, users commonly associate this feature with a mobile number that can be used to receive UPI payments. However, not every mobile number automatically works as a UPI Number. Support, registration requirements, and the relationship between a UPI Number and a UPI ID can vary by application.

How a UPI Number works

  1. Registration: The user registers with a compatible UPI application.
  2. Mobile verification: The application verifies the mobile number associated with the user's registration and eligible account.
  3. Availability check: The user checks whether the application supports registration or mapping of a UPI Number.
  4. Configuration: If supported, the user activates or configures the numeric identifier according to the application's instructions.
  5. Payment initiation: Another user enters the registered UPI Number in a compatible payment interface.
  6. Recipient confirmation: The payer checks the recipient's displayed name and other available payment details.
  7. Payment authorisation: The payer authorises the transaction using the required authentication method.

Important points

  • A UPI Number is a payment identifier, not a UPI PIN.
  • A phone number being registered with a bank does not automatically mean it can be used as a UPI Number.
  • Availability may depend on the UPI application, registration status, and applicable service rules.
  • Do not assume every UPI application can resolve every numeric identifier.
  • The payer should verify the recipient before authorising a payment.

Practical example: If a user has configured a supported mobile-number-based UPI payment identifier, another user may be able to initiate a payment using that number instead of typing the complete UPI ID. The recipient's details must still be verified before payment.

What Is the Difference Between a UPI ID and a UPI Number?

A UPI ID and a UPI Number serve a similar purpose: helping identify a recipient for a UPI payment. However, their formats and registration arrangements differ. A UPI ID is generally an alphanumeric virtual address, while a UPI Number is a numeric identifier that can be mapped to a UPI account or address through a supported service.

Key differences

  • Format: A UPI ID usually contains text, numbers, and an @ suffix; a UPI Number is numeric.
  • Example: An illustrative UPI ID is rahul123@bankname. A UPI Number may be a registered 10-digit mobile number where supported.
  • Identification: A UPI ID uses a virtual payment address, while a UPI Number uses a supported numeric identifier.
  • Registration: A UPI ID is created or assigned through an application. A UPI Number must be registered or mapped through a supported service.
  • Ease of sharing: A UPI ID requires sharing the complete address. A supported UPI Number can be convenient when the recipient's registered number is available.
  • Availability: Both depend on provider support and account eligibility; a UPI Number also depends on numeric-identifier registration.
  • Verification: For either identifier, check the recipient's displayed name before paying.

The examples are illustrative. Actual formats and eligibility depend on the service provider.

How to choose between them

  1. Use a UPI ID when you want to share a specific payment address, particularly for business payments or when the recipient has provided that address.
  2. Use a UPI Number when the recipient confirms that the numeric identifier is registered and supported by your payment application.
  3. Verify the recipient using the name displayed by the application before entering your UPI PIN.
  4. Keep a transaction record by checking the payment status and saving the transaction reference when necessary.
Neither a UPI ID nor a UPI Number is the same as a UPI PIN. Identifiers help route payments; the UPI PIN is a confidential authentication credential used to authorise applicable debit transactions.

Practical example: A customer may pay a shop using shopname@bankname or a supported registered numeric identifier. In either case, the customer should confirm the displayed business name before authorising payment.

How to Find Your UPI ID

Your UPI ID is generally available in the profile, bank account, or payment settings section of your UPI application. The precise steps depend on the application you use. Some apps provide a way to view UPI IDs through their bank-account settings.

Step-by-step process

  1. Open your UPI application. Launch the app in which you have registered your bank account.
  2. Sign in or unlock the application. Complete any required device authentication.
  3. Open your profile or account settings. Look for your profile picture, account icon, or payment settings.
  4. Select the linked bank account. If multiple accounts are linked, choose the account for which you want to find the UPI ID.
  5. Open the UPI ID or payment address section. It may be labelled UPI IDs, Manage UPI IDs, Payment addresses, or something similar.
  6. View your UPI ID. Identify the complete address, including the portion after the @ symbol.
  7. Copy or share it if needed. Use the application's built-in copy or share option where available.
  8. Confirm the details before sharing. Ensure you are sharing the intended UPI ID and not a different account's identifier.

What if you cannot find your UPI ID?

  • Check whether your bank account has been successfully linked.
  • Confirm that UPI registration is complete.
  • Look under the settings for the relevant bank account rather than only the general profile.
  • Update the application if the interface has changed.
  • Contact the application's official support team or your bank if the identifier is unavailable.

Safety precautions

  • Sharing a UPI ID to receive money does not require sharing your UPI PIN.
  • Do not disclose your OTP, UPI PIN, banking password, or other confidential authentication details.
  • Do not assume an identifier is active merely because it appears in an old transaction record.

Practical example: If your application displays rahul123@bankname under Manage UPI IDs, that is the address you can provide to someone who wants to send you money, provided it remains active and supported.

How to Create a UPI ID

A UPI ID is generally created or assigned when you register with a compatible UPI application and link an eligible bank account. Some applications allow users to create additional IDs or select from available address options. Registration requirements and the number of IDs permitted vary by provider.

Step-by-step process

  1. Choose a supported UPI application. Download an official application from a trusted app store or use your bank's official UPI service.
  2. Register your mobile number. Follow the application's verification process. The number generally needs to match the one registered with your bank account for account discovery.
  3. Complete the required device verification. Some applications use SMS-based verification or other supported checks.
  4. Select your bank. Find the bank that holds your eligible account.
  5. Link your bank account. Select the account detected by the application and follow the on-screen instructions.
  6. Set up your UPI PIN if required. Complete the bank-supported authentication process for the selected account. Never share the PIN.
  7. Open the UPI ID settings. Look for options such as Create UPI ID, Manage UPI IDs, or Add UPI ID.
  8. Choose an available ID. If customisation is supported, select an allowed prefix and an available provider suffix. Otherwise, use the ID assigned by the application.
  9. Confirm the setup. Complete any additional verification required by the application.
  10. Test the identifier carefully. View the newly created ID and confirm that it is associated with the intended account.

Example

Suppose a user wants a simple UPI ID for personal payments:

  • Preferred prefix: rahul123
  • Provider suffix: @bankname
  • Illustrative result: rahul123@bankname

The actual suffix is determined by the application, and the preferred prefix may already be taken or unavailable.

Common problems during creation

  • Mobile number mismatch: If the mobile number registered with your bank differs from the number verified in the UPI application, the account may not appear.
  • Bank account not detected: Confirm that the bank participates in the service and that your account is eligible for UPI.
  • Preferred ID unavailable: Try an alternative prefix or select one of the IDs offered by the application.
  • UPI PIN setup failure: Follow the bank's official instructions and verify that you are using an accepted authentication method.

Important points

  • Use only official applications and bank-authorised processes.
  • Never create or manage a UPI ID through an unknown link sent by a stranger.
  • Check a newly created ID before sharing it publicly.
  • Creating a UPI ID does not eliminate the need to protect your authentication credentials.

How to Share Your UPI ID Safely

A UPI ID is designed to make receiving digital payments easier. You may share it with customers, friends, family members, or other intended payers. Safe sharing means providing only the payment identifier and avoiding the disclosure of confidential information.

Step-by-step process

  1. Find your active UPI ID. Open the UPI application and verify the identifier associated with the intended bank account.
  2. Copy the complete ID. Use the application's copy function to reduce typing errors.
  3. Select a suitable sharing method. Send the ID through a trusted messaging service, email, or another appropriate communication channel.
  4. Check the recipient and message. Make sure the payment details are being sent to the intended person or business.
  5. Explain the purpose clearly. If you are sharing the ID to receive a payment, state the amount or purpose separately where relevant.
  6. Confirm receipt independently. Check your own UPI application or bank statement to verify whether the payment has arrived.
  7. Keep evidence for business payments. Retain relevant transaction references, receipts, or invoices when appropriate.

Information you can generally share

  • Your active UPI ID.
  • Your business name or payment instructions.
  • Your official payment QR code, where appropriate.
  • The amount and purpose of a requested payment.

Information you must never share

  • Your UPI PIN.
  • OTPs used to authenticate transactions or account changes.
  • Banking passwords or confidential login credentials.
  • Screen-sharing or remote-access permissions requested by an untrusted person.
  • Sensitive banking information unrelated to the payment.

Common scams to avoid

  • Fake payment confirmation: Someone shows a screenshot claiming to have paid you. Verify the credit in your own application or bank statement.
  • Fraudulent collect request: A person asks you to approve a request while claiming this is necessary to receive money. Review the request carefully; authorising it may send money from your account.
  • Impersonation: A caller pretends to be from a bank or payment application and requests your PIN or OTP. Do not disclose these details.
  • Suspicious QR code: Someone sends a QR code and claims that scanning it will credit money to your account. A payment QR code may instead initiate a payment from you. Check the action and recipient displayed by your application.

Practical example: A business owner can publish a UPI ID on an official website. Customers should verify the business name and check their transaction status after payment rather than relying solely on a screenshot.

How to Pay Someone Using Their UPI ID

UPI allows users to send money by entering a recipient's UPI ID through a supported application. The payment is directed through the UPI system, and the sender must complete the authentication required by the application and bank.

Step-by-step payment process

  1. Open your UPI application. Unlock it using your normal device authentication.
  2. Select the payment option. Choose an option such as Pay, Send Money, or Transfer.
  3. Enter the recipient's UPI ID. Type the complete identifier or paste the one provided by the recipient.
  4. Verify the recipient. Check the name displayed by the application. If the name does not match your intended recipient, stop and confirm the details.
  5. Enter the payment amount. Check the amount carefully before proceeding.
  6. Add a note if available. You may enter the purpose of the payment, such as an invoice number or purchase reference.
  7. Review the transaction. Confirm the recipient, amount, and selected funding account.
  8. Authorise the payment. Enter your UPI PIN when the application requests it for a debit transaction.
  9. Wait for the result. Do not assume the transaction is complete until the application reports its status.
  10. Save the reference. Keep the transaction ID or receipt for future reference.

Example

Suppose you need to pay a service provider ₹750:

  • Recipient's UPI ID: service123@bankname (illustrative).
  • Amount: ₹750.
  • Purpose: Service payment.
  • Final check: Verify the displayed recipient name and amount.
  • Authorisation: Enter your UPI PIN only in the official application when required.

A payment may complete within seconds, but network or bank issues can sometimes cause a pending or failed status.

What to do after payment

  • Successful: Check that the amount was debited and the transaction is recorded as successful.
  • Pending: Check the transaction status and avoid immediately repeating the payment.
  • Failed: Check whether the amount was debited and follow the application's or bank's instructions.
  • Wrong recipient: Save the transaction reference and report the issue promptly to your payment application and bank.
You generally do not need to enter your UPI PIN simply to receive money. Never authorise an unfamiliar request under the impression that entering your PIN is necessary to collect a payment.

Can You Use Your Mobile Number as a UPI Number?

Yes, a mobile number can be used as a UPI Number when the relevant application and service support it and the number has been properly registered or mapped. However, a mobile number is not automatically a valid UPI Number simply because it is linked to a bank account.

Provider terms and implementation can differ. Some services may use the registered mobile number as the UPI Number, subject to the applicable registration and mapping process. Other providers may implement the feature differently.

Step-by-step process to check eligibility

  1. Open your UPI application. Use the application in which you have registered your bank account.
  2. Check your profile or payment settings. Look for the UPI Number, mobile-number-based payments, or equivalent option.
  3. Verify your registered mobile number. Confirm that the number shown is the one you intend to use.
  4. Check the registration status. Follow the application's instructions to register, activate, or map the number if the feature is available.
  5. Confirm the linked account. Check the payment account associated with the identifier, where the application provides this information.
  6. Check availability with your provider. If you cannot find the feature, consult the application's official help resources.
  7. Perform a cautious test if appropriate. Ask a trusted person to verify the recipient details before making a small payment, if needed.

Important conditions

  • The number must satisfy the application's registration requirements.
  • The bank account and UPI registration must be eligible for the relevant service.
  • The feature may not be available in every application.
  • A mobile number may be associated with different payment services or accounts, so do not assume that entering a number will always identify the intended person.
  • A mobile number and a UPI ID remain different identifiers, even if they are linked.

What if you change your mobile number?

If you change your phone number, SIM card, or registered mobile number, check your bank and UPI application's requirements before relying on the old identifier. Depending on the change, you may need to update your bank records, complete mobile verification again, or re-register for UPI. Changing a SIM, mobile number, or payment service provider's application can require re-registration.

Practical example: If a customer intends to pay your mobile-number-based UPI identifier, ask them to verify the name shown in their payment application before authorising the transfer.

How to Manage Your UPI ID

Managing a UPI ID means viewing, creating, selecting, sharing, or changing the identifiers available for your linked payment accounts, where the application supports those functions.

Some applications allow multiple UPI IDs for an account. The available options and limits are provider-specific.

Step-by-step management process

  1. Open the UPI application. Sign in using the normal secure process.
  2. Go to the profile or bank account section. Find the account whose UPI IDs you want to manage.
  3. Select the UPI ID management option. Look for Manage UPI IDs or a similarly named menu.
  4. Review existing IDs. Check which identifiers are displayed and whether the application identifies a default or preferred option.
  5. Add an ID if supported. Select an available ID or create an additional one according to the application's instructions.
  6. Review the default payment settings. If the application supports a default ID or receiving preference, make sure it is configured as intended.
  7. Check sharing details. Update saved payment instructions, invoices, or public listings if you change the ID you use for receiving money.
  8. Review old payment links and QR codes. Confirm that they still direct payments to the intended recipient.
  9. Keep your details secure. Never share your UPI PIN while managing identifiers.
  10. Verify the changes. Reopen the settings and confirm that the intended ID is available and correctly associated with your account.

Good management practices

  • Use a clear, recognisable identifier for regular business transactions when possible.
  • Keep personal and business payment details organised.
  • Maintain accurate payment instructions on websites, invoices, and printed materials.
  • Review the destination of older QR codes before distributing them again.
  • Avoid changing identifiers without updating the payment details shared with customers.
  • Contact the provider if an identifier disappears or becomes unavailable unexpectedly.

Can you delete or change a UPI ID?

The ability to add, remove, deactivate, or change an ID depends on the application and its rules. Some services may allow you to disable an identifier or create a replacement rather than directly rename an existing one.

Before changing an ID, check whether pending payments, recurring payment arrangements, saved QR codes, or other services depend on it.

Practical example: If a shop changes its displayed UPI ID, it should update its website, invoices, and payment-counter QR code and verify that customers are directed to the correct business account.

What to Do If a UPI ID Cannot Be Found

A UPI ID may fail to resolve because it was entered incorrectly, is inactive, is not registered with the relevant service, or cannot be resolved by the particular payment application. Network problems or temporary service interruptions may also affect a transaction.

Step-by-step troubleshooting

  1. Check the spelling. Compare the entered UPI ID with the exact address supplied by the recipient.
  2. Check the complete identifier. Make sure the prefix, @ symbol, and provider suffix are all included.
  3. Ask the recipient to confirm the ID. The recipient should view the identifier in their own UPI application rather than relying on an old message.
  4. Check the recipient's registration. Ask whether the ID is still active and associated with an eligible account.
  5. Try the supported search method. If your application supports entering a UPI ID directly, use that feature instead of assuming every search or contact option works identically.
  6. Check your internet connection. Restore a stable connection and retry if the application reports a connectivity issue.
  7. Check for a service interruption. Follow the official status messages or support guidance provided by your application or bank.
  8. Update the application if needed. Install updates only from an official source.
  9. Try another supported payment method if appropriate. You may use another verified UPI ID or a bank-account transfer method supported by your application.
  10. Contact official support. If the problem persists, provide the error message and relevant transaction or support reference, if one exists.

Common causes and recommended actions

  • Typing error: Re-enter the exact UPI ID.
  • Incorrect provider suffix: Ask the recipient to copy the ID from the app.
  • Inactive or unavailable ID: Ask the recipient to verify its current status.
  • Bank account not detected: Check mobile-number matching and account eligibility.
  • Temporary connectivity issue: Restore connectivity and retry.
  • Unsupported identifier: Use an identifier or payment method supported by both parties.
  • Repeated resolution failure: Contact the official application or bank support team.

If money has already been debited

If the payment has already been initiated, do not immediately repeat it just because the recipient's application does not show the money.

  1. Open your transaction history.
  2. Check whether the transaction is successful, pending, or failed.
  3. Save the transaction reference number.
  4. Ask the recipient to check their bank account and transaction history.
  5. Follow the official complaint process if the status remains unresolved.
A payment failure and a payment that is merely not visible to the recipient are not necessarily the same situation. Verify the transaction status before taking further action.

How to Check the Recipient's Name Before Paying

Verifying the recipient's displayed name is an important step before authorising a UPI payment. A correctly formatted UPI ID does not, by itself, guarantee that you have selected the intended person or business.

Supported UPI applications may display a recipient name after the payer enters an identifier or starts the payment flow. Always review the information provided by the application before proceeding.

Step-by-step verification process

  1. Enter the recipient's UPI ID. Use the identifier provided directly by the intended recipient or from a trusted source.
  2. Wait for the application to resolve it. Do not proceed while the recipient information is missing or still loading.
  3. Read the displayed name carefully. Check the name shown by the application against the person or business you intend to pay.
  4. Compare the details. For a business, check the business or merchant name against the invoice, official website, or payment instructions. For an individual, confirm the identity through a trusted channel.
  5. Confirm the amount. Make sure the payment amount matches the agreed amount.
  6. Check the payment purpose. Verify any reference, invoice number, or description displayed before proceeding.
  7. Stop if anything is inconsistent. Do not authorise the payment if the name is unexpected, unclear, or materially different from the intended recipient.
  8. Confirm through an independent channel. Contact the recipient using a previously verified phone number or official contact method if clarification is required.
  9. Authorise only after verification. Enter your UPI PIN in the official payment application only when you are ready to approve the payment.
  10. Save the transaction record. After payment, check the status and retain the transaction reference.

What if the name does not match?

  • Do not assume that the mismatch is harmless.
  • Ask the intended recipient to confirm the correct UPI ID.
  • Check whether the payment is being made to an individual, business, or authorised collection account.
  • Do not proceed until you understand the discrepancy.
  • If you suspect impersonation or fraud, stop the transaction and report it through the appropriate official channel.

What if the displayed name is unfamiliar?

Some payment arrangements may show a legal account-holder name, a merchant name, or another supported name format. An unfamiliar name does not automatically prove fraud, but it must be clarified before payment.

Practical example: An invoice says the payment should go to ABC Services, but the application displays an unrelated individual. Do not enter your UPI PIN until the business confirms the correct payment details through a trusted channel.

Verify the recipient, amount, and purpose before authorising payment. Never rely only on a logo, QR-code image, payment screenshot, or message claiming that an account belongs to a particular person.

What Happens If You Send Money to the Wrong UPI ID?

Sending money to the wrong UPI ID can result in the amount being credited to an unintended recipient if the transaction is successfully completed. UPI payments are not automatically reversed simply because the sender made a mistake.

The appropriate next step depends on the transaction status, the bank's procedures, and whether the payment was unauthorised or initiated by mistake. Report the issue promptly and retain the transaction reference.

Step-by-step action plan

  1. Check the transaction status. Open your UPI application's transaction history and determine whether the payment is successful, pending, or failed.
  2. Save the transaction details. Record the transaction reference or UPI transaction ID, date, time, amount, and relevant recipient details.
  3. Do not repeat the payment. A second transfer may create another loss if the original payment has already succeeded.
  4. Report the problem through the application. Open the relevant transaction and use the official Help, Report an issue, or equivalent option if available.
  5. Contact your bank promptly. Explain that the transfer was made to an unintended recipient and provide the transaction details.
  6. Request formal dispute handling. Ask the bank or payment provider to register the complaint and explain the applicable recovery process.
  7. Follow the complaint reference. Keep the complaint number and respond to requests for supporting information through official channels.
  8. Provide only necessary evidence. Submit transaction records or other relevant documents through the bank's or provider's official process.
  9. Escalate if unresolved. Follow the applicable grievance process, including the relevant UPI provider or bank escalation channel and the appropriate banking ombudsman mechanism where eligible.
  10. Monitor the outcome. Check official communications and transaction records for any update or credit.

What happens in different situations?

  • Successful: The payment has been recorded as completed. Report the wrong transfer promptly and request recovery assistance.
  • Pending: The final outcome has not yet been confirmed. Check the status and avoid sending the payment again immediately.
  • Failed: The transaction was reported as unsuccessful. Verify whether the amount was debited and follow the bank's instructions.
  • Unauthorised: You did not approve or initiate the transaction. Report it immediately through your bank's official fraud-reporting process.
  • Suspected scam: You were deceived into making the payment. Contact your bank and report the incident promptly through official channels.

Can a wrong UPI payment be reversed?

Recovery may be possible, but it is not guaranteed. A completed payment may require investigation and coordination between the relevant banks or payment providers. The outcome can depend on the circumstances, available evidence, and applicable rules and procedures.

Do not assume that a bank can automatically debit the recipient's account without following the relevant process.

What if you suspect fraud?

If the transfer was connected to a scam, act immediately:

  • Contact your bank using its official customer-support channel.
  • Report the transaction through your UPI application.
  • In India, report suspected cyber financial fraud through the official National Cyber Crime Reporting Portal at cybercrime.gov.in or call the national cybercrime helpline 1930, as appropriate.
  • Keep transaction IDs, messages, phone numbers, and other relevant evidence.
  • Do not pay anyone who promises guaranteed recovery in exchange for an advance fee.
  • Never disclose your UPI PIN or OTP to someone claiming to help recover your money.

How to prevent wrong UPI payments

  1. Copy the recipient's UPI ID instead of typing it manually where possible.
  2. Check the recipient's displayed name before authorising payment.
  3. Verify the amount and purpose.
  4. For a new recipient, consider confirming the payment details through a trusted channel.
  5. Use official applications and avoid suspicious payment links.
  6. Review your transaction status after every payment.

Practical example: If you intend to pay ₹2,000 to a supplier but accidentally send the money to another UPI ID, save the transaction reference, report the issue through your payment application, and contact your bank immediately. Explain that it was an unintended transfer and follow the bank's formal recovery process.

Quick Summary and Essential Safety Rules

  • A UPI ID is a virtual payment address, while a UPI Number is a numeric identifier supported by certain services.
  • Find or create identifiers only through your official UPI application or bank-supported service.
  • Check that the identifier is active and associated with the intended account before sharing it.
  • Verify the recipient's displayed name, amount, and payment purpose before authorising a payment.
  • Never share your UPI PIN, OTP, banking password, or confidential login credentials.
  • You generally do not need to enter your UPI PIN to receive money.
  • Check the transaction status in your own application or bank statement; do not rely solely on screenshots or messages from another person.
  • If a payment is pending, avoid immediately repeating it while the outcome is uncertain.
  • If you send money to the wrong person or suspect fraud, save the transaction details and contact your bank and payment provider promptly.
Key takeaway: UPI IDs and supported UPI Numbers make payments easier, but they do not replace careful recipient verification. Use official apps, protect your authentication credentials, and check every transaction before and after payment.

Practical checks before you act

A UPI ID is an address used to route a payment; it is not proof that the intended recipient owns the ID.

  • Confirm the payee name shown by your payment app.
  • Send a small test amount only when appropriate and with the recipient’s agreement.
  • Avoid relying on an old screenshot or copied ID without checking it again.

For a UPI ID or number-based payment, verify the resolved recipient name and intended amount in the payment app before authorizing the debit; an address alone does not establish identity.
